# free-in-barna
We are writing FreeInBarna, a place for people to find cultural activities and places that are free.

## Input from stakeholders
- Mary wants a reliable site with a popular stack based on TypeScript, giving users a dashboard for easy access to information.
- Susan has a set of features about museums and their free days, free activities per month, and which ones require appointments.
- Steve wants an attractive site that works well with a modern browser.
